# Pack RAG — Voyage en Crète

Pack documentaire Markdown prêt à intégrer dans le RAG Digital Blue Skye.

## Contenu

- 12 fiches thématiques Markdown.
- 1 index documentaire.
- 1 fichier sources officielles.
- Métadonnées YAML en tête de chaque fichier.

## Usage recommandé

1. Ajouter le dossier `rag-voyage-crete` dans le dépôt documentaire.
2. Indexer les fichiers `.md`.
3. Utiliser les champs YAML comme métadonnées.
4. Découper les documents en chunks de 500 à 900 mots avec overlap de 80 à 120 mots.
5. Marquer les informations évolutives comme à vérifier avant réponse définitive.
