# Templates documentaires Digital Blue Skye

Ce dossier regroupe les modeles de livrables utilises comme reference pour la phase de generation documentaire de l'agent IA.

Modeles disponibles :
- Fiche projet
- Benchmark
- SWOT
- RACI
- Cahier des charges
- Note de veille
- Strategie editoriale
- Audit UX
- Support de soutenance
- Portfolio

Chaque template est concu pour produire un document exportable en Markdown, HTML, PDF ou DOCX depuis l'assistant IA.
